--------------------------------------------------------------------
  PHASE 6 — WHAT HAPPENS DURING TRAINING
--------------------------------------------------------------------

  The training script (src/train_leonardo.py) does this automatically:

   * Resumes from the last checkpoint if the job was killed (24h wall-clock
     limit). Simply re-submit the job and it picks up where it left off.
   * Saves a checkpoint every 2000 steps to latest.pth (atomic, no corruption).
   * Saves an epoch checkpoint to epoch_001.pth, epoch_002.pth, etc.
   * After all epochs complete, saves backbone_final.pth — the file you need
     for export and deployment.

  Checkpoint directory:
    /scratch/a08trc28/facial-recognition/checkpoints/run_<JOBID>/

--------------------------------------------------------------------
  PHASE 9 — EXPORT TO ONNX (ON LEONARDO, OR LOCALLY)
--------------------------------------------------------------------

  On Leonardo (login node is fine, no GPU needed):
    cd /scratch/a08trc28/facial-recognition
    pixi run python src/export.py \
      --checkpoint checkpoints/run_<JOBID>/backbone_final.pth \
      --onnx-out model.onnx

  Or on your LOCAL machine (if you have onnx/onnxruntime installed):
    python src/export.py \
      --checkpoint backbone_final.pth \
      --onnx-out model.onnx

  The ONNX file can then be copied anywhere.

--------------------------------------------------------------------
  PHASE 10 — RUN LOCAL INFERENCE
--------------------------------------------------------------------

  On your LOCAL Windows machine (RTX 5070), once you have model.onnx:

    # Install the inference dependencies
    pip install opencv-python onnxruntime  # onnxruntime-gpu for CUDA

    # Run inference on an aligned 112x112 face image
    python src/inference.py --model model.onnx --image face.jpg --l2-normalize

    # Save the embedding to a .npy file
    python src/inference.py --model model.onnx --image face.jpg --l2-normalize --save-npy embedding.npy

--------------------------------------------------------------------
  PHASE 11 — BUILD TENSORRT ENGINE (OPTIONAL, LOCAL ONLY)
--------------------------------------------------------------------

  TensorRT engines are GPU-specific. Build on your RTX 5070, NOT on Leonardo's A100s.

  On your LOCAL machine:
    # First export ONNX, then convert to TensorRT engine
    python src/export.py \
      --checkpoint backbone_final.pth \
      --onnx-out model.onnx \
      --build-trt \
      --engine-out model.engine

  Then run inference with the engine:
    python src/inference.py --model model.engine --image face.jpg --l2-normalize
